# 红果冻 Switch 版（hongguo-borealis）

红果冻（红果短剧）的 Nintendo Switch 原生客户端，基于 libnx + borealis + 自编译 libmpv。
**仅供学习交流，完全免费，禁止用于任何商业用途。**

## 下载

最新版本见本仓库 Releases 页面：`https://github.com/zys123444444-dotcom/zys123444444-dotcom.github.io/releases`

- 单文件分发：只需要 `hongguo-borealis-vX.Y.Z.nro`，解压/拷贝到 SD 卡 `/switch/` 目录即可
- 无外部依赖：所有库与资源（主题/图标/字体）都打包在 NRO 内
- 首次启动会自动注册匿名身份；换设备/换网络无需任何配置

## 功能

- 首页榜单 / 追剧 / 最近观看 / 下载页
- 在线播放（2x 倍速无掉帧）、本地播放
- 进度条拖动、选集浮层、横竖屏切换（ZR）
- 设置页：播放解码、检查更新（支持远端 JSON 文案）、关于本机、开源声明

## 操作

| 按键 | 功能 |
|---|---|
| A | 进入 / 播放暂停 |
| B | 返回（首页连按两次退出） |
| X | 首页/追剧：追剧标记 |
| Y | 刷新首页 |
| ZR | 横竖屏切换 |
| ← / → | 快退 / 快进 10 秒 |
| ↑ / ↓ | 上一集 / 下一集 |
| L / R | 切换分类 |
| LT / RT | 切换页签 |

## 版本 2.0.0 更新摘要

- 修复 2x 倍速掉帧（mpv 帧丢弃策略误判）
- 首帧加载 12.4s → 1.0~1.5s
- 网络层收口为单一执行层（消除周期性崩溃）
- 播放页触摸/焦点全线修复（按钮、进度条、蓝色焦点框）
- 取流域名自动轮换（某镜像不可用时自动换下一个）
- 检查更新支持远端 JSON 文案与公告
